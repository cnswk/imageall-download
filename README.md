# MoaWing 내려받기

MoaWing 런처와 그 안의 프로그램(ImageAll 2 등) 배포 파일만 있는 곳입니다(소스는 비공개).

- **MoaWing 런처**: [Releases](https://github.com/cnswk/imageall-download/releases)에서 가장 새 `MoaWingLauncher.exe`를 받아 실행하세요.
  런처 왼쪽 목록에서 프로그램을 고르고 [설치]를 누르면 됩니다. 새 버전이 나오면 런처가 알아서 업데이트해요.
- 모든 파일은 서명되어 있고, 런처는 서명이 맞을 때만 설치해요.
- 업데이트해도 `작업`·`설정.json`·`기록`·`maa_data`는 그대로예요.

## 확장 프로그램(크롬)

웹 스토어에 올리지 않은 확장 프로그램은 MoaWing 런처의 '확장 프로그램'에서 [설치] → [크롬에 넣기]를 누르고,
크롬 '확장 프로그램' 화면에서 [개발자 모드]를 켠 뒤 [압축해제된 확장 프로그램을 로드합니다]로 설치 폴더를 고르세요.
