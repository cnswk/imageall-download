# ImageAll 내려받기

ImageAll 런처와 ImageAll 2 배포 파일만 있는 곳입니다(소스는 비공개).

- **ImageAll 런처**: [Releases](https://github.com/cnswk/imageall-download/releases)에서 `ImageAllLauncher.exe`를 받아 실행하세요.
  런처에서 ImageAll 2를 고르고 [설치]를 누르면 됩니다. 새 버전이 나오면 런처가 알아서 업데이트해요.
- 모든 파일은 서명되어 있고, 런처는 서명이 맞을 때만 설치해요.
- 업데이트해도 `작업`·`설정.json`·`기록`·`maa_data`는 그대로예요.
