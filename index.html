MoaWing 런처

내 프로그램을 한 곳에서. 목록에서 고르고 [설치] → [플레이]. 새 판이 나오면 알아서 업데이트해요.

Windows용 내려받기
Windows 10 · 11 (64비트) · 설치 없이 바로 실행

쓰는 법

1

받기

위의 [Windows용 내려받기]를 눌러 MoaWingLauncher.exe를 받아요.

2

실행

받은 파일을 더블클릭해요. 파란 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행].

3

설치·플레이

왼쪽 목록에서 프로그램을 고르고 [설치], 다 되면 [플레이].

이런 점이 좋아요

알아서 업데이트

새 판이 나오면 런처가 받아서 바꿔 둬요. 런처 자신도 스스로 새것이 돼요.

가짜 파일은 설치 안 함

모든 파일에 만든 사람의 서명이 있어요. 서명이 안 맞으면 런처가 설치하지 않아요.

내 파일은 그대로

업데이트해도 작업·설정·내보낸 영상 같은 내 파일은 건드리지 않아요.

처음 실행할 때

아직 마이크로소프트 코드 서명 인증서가 없는 프로그램이라, 처음 켤 때 윈도우가 "Windows의 PC 보호" 창을 띄울 수 있어요. [추가 정보]를 누른 뒤 [실행]을 누르면 돼요. 런처 안에서 받는 프로그램은 런처가 서명을 확인해요.
MoaWing · 파일은 GitHub 내려받기 페이지에서도 받을 수 있어요.
